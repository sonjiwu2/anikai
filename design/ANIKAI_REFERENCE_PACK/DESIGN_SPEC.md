# Anikai — компактная дизайн-спецификация

|---|---|
| Основной фон | `#121318` |
| Поверхность | `#1B1D24` |
| Приподнятая поверхность | `#252832` |

| Вторичный текст | `#A2A6B1` |

| Акцент hover | `#96ACFF` |

Зелёный/лайм запрещён в UI. Канонические цвета иллюстраций разрешены. Проверять контраст после выбора шрифта и размеров.

## Пропорции и поведение

| Элемент | Пропорция | Fit |
|---|---|---|
| Постер | 2:3 | cover, индивидуальная focal point |
| Превью эпизода | 16:9 | cover |
| Карточка продолжения | 16:9 | cover |
| Видео | контейнер 16:9 | contain |
| Аватар | 1:1 | cover |
| Обложка списка | около 2.4:1 desktop / 2:1 phone | cover |
| Hero | responsive, не жёсткий ratio | индивидуальный crop |

Не растягивать файл по независимым ширине и высоте. Резервировать пространство до загрузки. Lazy load вне первого экрана. Hero — приоритетная загрузка активного слайда. Fallback обязателен.

## Сетка и размеры

- Шкала отступов: 8/12/16/20/24/32/40/48px.
- Горизонтальные gutters: 16px phone, 24px tablet, 32–48px desktop.
- Максимальная ширина основного контента: около 1440px, с центрированием.
- Header: 56–60px phone, 72–76px desktop.
- Touch target: минимум 44x44px.
- Control height: 40–44px desktop, минимум 44px phone.
- Radii: controls 8px, cards 10px; круги только для соответствующих иконок/аватаров.
- Icons: 20–24px; stroke 1.75–2px.
- Базовый текст: 14–16px; secondary meta 12–13px при читаемом контрасте.
- Heading страницы: 28–36px desktop, 24–30px phone.
- Hero heading: 40–56px desktop, 28–36px phone.

## Mobile

Нижняя навигация на 4 раздела с safe-area и padding контента. Фильтры в sheet. Видео над списком эпизодов. Настройки в одну колонку. Постеры — 2 колонки phone; число колонок выше увеличивать только при достаточной ширине карточки. Горизонтальная прокрутка допустима только внутри специально выбранной полосы, а не всей страницы.

## Единые состояния

Default, hover, focus-visible, pressed, selected, disabled, loading, empty, error. Для успеха — синий/нейтральный цвет плюс текст/иконка. Анимации 150–220ms; reduced-motion вариант без лишних движений.
