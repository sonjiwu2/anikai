## Что сохранить

Графитовую основу, спокойный синий акцент, чистый кириллический гротеск, контурные SVG-иконки, узнаваемые аниме, ясную иерархию и одинаковые компоненты между страницами.

## Что исправить при реализации

- YORU/yoru везде заменить на Anikai/anikai; сделать подходящий логотип, favicon и метаданные.
- Числа результатов/просмотров и counters вычислять из данных.
- Не копировать фиктивные рейтинги/расписание/названия серий как официальные факты.
- Текущая секция при просмотре — каталог; ошибочный active state на исходном player исправить.
- Замки на непросмотренных эпизодах означают визуальную защиту от спойлеров, а не запрет просмотра.
- «Отзывы/Обсуждение» без backend заменить локальными заметками с таймкодами.
- Не обещать публичность профиля/уведомления в закрытом браузере без реальной инфраструктуры.
- Качество, озвучки и субтитры отображать только при наличии соответствующих реальных источников.
- Mobile-версии не приложены: разработать их по правилам мастер-промпта, а не уменьшать desktop целиком.

Референсы — не готовые web assets. Из них нельзя получить настоящий исходный видеоконтент или официальный комплект постеров.
