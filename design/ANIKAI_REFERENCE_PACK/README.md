# Anikai — референсы и задание для Claude Code

Этот пакет содержит финальные дизайн-референсы аниме-видеосервиса, подробное техническое и дизайнерское задание и чек-лист приёмки.

## Быстрый старт

1. Распакуйте архив в папку проекта, например `design/ANIKAI_REFERENCE_PACK/`.
2. Откройте корень проекта в Claude Code.
3. Вставьте короткую команду из `START_HERE.txt` либо полный текст `CLAUDE_CODE_MASTER_PROMPT.md`.
4. Дайте Claude доступ к этой папке: он должен прочитать документы и посмотреть PNG-файлы.

Архив не надо прикреплять как непрозрачный бинарный файл: для Claude Code удобнее обычные распакованные файлы в рабочей папке.

## Состав

- `CLAUDE_CODE_MASTER_PROMPT.md` — главное подробное задание.
- `START_HERE.txt` — короткая команда для начала работы.
- `REFERENCE_MAP.md` — связь изображений со страницами и приоритеты референсов.
- `DESIGN_SPEC.md` — основные токены, размеры и правила адаптации.
- `QA_CHECKLIST.md` — приёмка поведения и адаптивности.
- `ASSET_MANIFEST.json` — размеры и контрольные суммы референсов.
- `TECHNICAL_SOURCES.md` — официальная документация для реализации.
- `references/` — 9 оригинальных полноразмерных PNG.

## Название и изображения

Название готового продукта — **Anikai**. На оригинальных картинках остался прежний логотип YORU/yoru: это только историческая надпись в референсе. Её необходимо заменить в реальном интерфейсе. Сами референсы сохранены без потери качества и без повторной генерации.

Графитово-синий вариант окончательный. Старые зелёные/сиреневые варианты и промежуточное расписание в пакет не включены.

Картинки показывают дизайн и узнаваемые реальные аниме; иллюстрации в них сгенерированы. Они не являются комплектом официальных постеров, отдельными SVG-иконками или файлами видео. Для реализации нужны отдельные изображения и настоящий доступный видеоисточник. Не строить интерфейс как картинку и не считать демонстрационные даты/рейтинги фактическими данными.

## Граница frontend-only

Сайт не требует собственного backend. Коллекция, профиль, заметки и прогресс сохраняются локально. Автоматической синхронизации между устройствами и настоящих публичных обсуждений нет. В задании обсуждения заменены локальными заметками. Для видео предусмотрен проверенный демонстрационный источник с честной подписью и удобной последующей заменой.

## Приоритет требований

Пользовательское название и ограничения → мастер-промпт → дизайн-спецификация → изображения. Если на картинке встречается ошибка, странный заголовок, несогласованное состояние или лишняя функция, исправлять её по смыслу задания.
